# agents/

Curated source of truth for AI agent behavior and harness configuration.

This directory holds **copies** of the live agent configs, not symlinks.
The live directories stay where they are; when a file here changes, copy it
back to the live location (or re-copy from live after editing there, then
update this copy).

## Layout

```
agents/
├── AGENTS.md          # canonical agent behavior (operating principles)
├── pi/                # mirrors ~/.pi/agent (curated subset)
│   ├── models.json    # provider/model definitions (llama.cpp etc.)
│   ├── settings.json  # pi settings (packages, defaults, compaction)
│   ├── extensions/    # extension configs (code lives in npm/, managed by pi)
│   │   └── pi-permission-system/config.json
│   ├── agents/        # pi-subagents custom agent definitions (*.md)
│   └── skills/        # pi skills (SKILL.md dirs)
├── codex/             # mirrors ~/.codex (curated subset)
│   ├── config.toml    # codex config (provider, projects, features)
│   ├── local.config.toml
│   ├── agents/        # codex custom agents
│   └── skills/        # codex skills (SKILL.md dirs)
└── llm/               # local LLM stack configs (see llm/README.md)
    └── llama-cpp/
        └── server.md  # current llama.cpp server setup (docker/localai)
```

## What is NOT here (runtime state, never copy)

- `~/.pi/agent/`: `sessions/`, `npm/` (installed extension code),
  `pi-hermes-memory/`, `projects-memory/`, `auth.json`, `trust.json`,
  `models-store.json`, `*.bak`
- `~/.codex/`: `sessions/`, `*.sqlite*`, `logs/`, `log/`, `auth.json`,
  `installation_id`, `shell_snapshots/`, `tmp/`, `model-catalog.json`
  (generated by `docker/localai/codex/make-catalog.py`)

## Syncing

Live → here (refresh after editing live configs):

```sh
cp ~/.pi/agent/{AGENTS.md,models.json,settings.json} agents/pi/
cp ~/.pi/agent/extensions/pi-permission-system/config.json \
   agents/pi/extensions/pi-permission-system/config.json
cp ~/.codex/{config.toml,local.config.toml} agents/codex/
```

Here → live (apply after editing here):

```sh
cp agents/AGENTS.md ~/.pi/agent/AGENTS.md
cp agents/pi/models.json ~/.pi/agent/models.json
cp agents/pi/settings.json ~/.pi/agent/settings.json
cp agents/pi/extensions/pi-permission-system/config.json \
   ~/.pi/agent/extensions/pi-permission-system/config.json
cp agents/codex/config.toml ~/.codex/config.toml
cp agents/codex/local.config.toml ~/.codex/local.config.toml
```

## Conventions

- **AGENTS.md** at the top level is the canonical behavior file. Pi reads
  `~/.pi/agent/AGENTS.md`; codex reads project-level `AGENTS.md` files, so
  copy it into repos (or `~/.codex/`) where it should apply.
- **Subagents**: pi-subagents custom agents are markdown files with
  frontmatter, discovered from `~/.pi/agent/agents/**/*.md` (user scope) or
  `.pi/agents/**/*.md` (project scope). Keep user-scope definitions in
  `pi/agents/`.
- **Skills**: `SKILL.md` files in directories. Pi user skills live under
  `~/.pi/agent/skills/` (and extension-provided skills under their npm
  packages); codex skills live under `~/.codex/skills/`.
- **Secrets never go here.** `auth.json` files and API keys stay out of git.
  Local providers use dummy keys (`local-not-needed`).
- **LLM**: model weights and the docker stack live outside this directory —
  see `llm/README.md`. The docker compose is in `../docker/localai/`.
